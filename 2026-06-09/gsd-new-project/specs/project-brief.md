# Project Brief

## Project Name

Library Management System

## Goal

Develop a simple Library Management System that allows administrators to manage books and members to borrow and return books efficiently.

The system provides accurate book availability information and maintains borrowing records in a relational database.

## Scope

The system includes:

- Admin book management.
- Member book borrowing.
- Member book returning.
- Borrowing history records.
- Book stock availability tracking.

The system does not include:

- Payment processing.
- Fine calculation.
- Advanced user registration.
- Password encryption for production use.

## Target Users

### Admin

Admins manage book records, monitor borrowing transactions, and maintain book availability.

### Member

Members view available books, borrow books, and return books they have borrowed.

## Technology Summary

- Backend: Python standard library HTTP server.
- Database: SQLite relational database.
- Frontend: Server-rendered HTML and CSS.
- Tests: Python `unittest`.
